# 如何在VSCODE中调试

## 编译

首先需要使用colcon将项目编译成debug模式。

```bash
# 编译全部节点
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Debug --symlink-install
# 编译指定节点
colcon build --packages-select <name_of_package> --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Debug  
# 指定build\install路径
colcon build --build-base build_debug --install-base install_debug --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Debug

# --symlink-install -》 通过链接代替拷贝
```

## 调试单节点

### 创建launch.json(node)

- 点击左侧工具栏 - run and debug
- 点击链接create a launch.json file， 生成模板c++

## 修改launch.json

修改program和arg（如有必要）,将启动项目设置为指定节点

## 调试launch.py

确保已安装ROS2的插件

### 创建launch.json(launch)

- 点击左侧工具栏 - run and debug
- 点击链接create a launch.json file， 生成模板ROS2 launch
