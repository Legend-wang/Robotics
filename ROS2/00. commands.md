# 常用命令

## Linux

### 文件

- vim: 打开文件
- rm: 删除文件或文件夹
  - i: 需要确认
  - f: 强制删除
  - r: 递归删除

## ROS2

### 节点

- ros2 run [node]: 执行节点

### 参数

- ros2 param list: 列出所有节点的参数
- ros2 param set [node] [para] [value]: 设置参数
- ros2 param get [node] [para]: 获取参数
- ros2 param dump [node]: 显示节点参数，输出到控制台，也可以重定向到文件
- ros2 param load [node] [file]: 加载参数
- ros2 param describe [node] [para]: 获取参数描述
